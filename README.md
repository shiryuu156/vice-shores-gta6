Vice Shores — an open-world crime game in the spirit of GTA 6, built in three.js. Rook, a getaway driver, owes fixer Marla Voss $40,000. Explore a procedural 5×5 city on foot and by car, steal cars, dodge a 0–5 star wanted level with chasing police, run 3 scripted story missions, fight pistol combat, and pay the debt down — with a HUD, live minimap, save/continue, and synthesized WebAudio sound. All city, characters, vehicles, names, story, art and sound are original. Static files, no network requests.

## Run it

```sh
npx serve game
```

Then open the served page in a desktop browser. Keyboard + mouse: WASD to move/drive, Shift to sprint, Space to jump, F to punch, E to enter/exit cars and start jobs, M for missions.
